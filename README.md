# 가온자리 진단툴 (2차 시안 + 3차 반영)

가온자리한의원 진료 보조 화면입니다. 단일 HTML 파일(`index.html`)로 되어 있고, GitHub Pages로 배포됩니다.

- 주소: https://mujusang.github.io/gaonjari-dx/
- 구성: 원장님 진료(클릭형) · 환자 문진표(체크형) · 문진표 사진(판독 미연동 · 수동 보정)
- 2차에서 더한 것: 생년월일→만 나이 자동, 전화번호·주소·이메일, 키·몸무게 분리와 BMI, 증상 다중선택·심한 순위·통증 0~10(10=견딜 수 없는 통증), 복진 부위·소견 상세(복량(伏梁)·심하비견·수분혈·신복직근·계령괴·소복불인·구급·현급·종비·급결·어혈·흉협 3구분·위내정수·제상동계)와 위치 직접 추가, 맥을 비롯한 문진 항목 전부 다중선택
- 3차 반영(2026-11-25 · 원장님 구술): `복량(伏梁)` — 배꼽 위에서 명치(심하)까지 임맥을 따라 대들보처럼 뻗쳐 만져지는 단단한 덩어리, 大陷胸湯의 핵심 복진 지표로 연결. `계령괴` — 배꼽 구멍 옆, 신복직근(복직근)과 배꼽 사이(주로 왼쪽)에서 우동가락만 하게 만져지는 딱딱한 경결, 血·어혈 지표로 桂枝茯苓丸에 연결. 柴胡劑를 쓸 때 계령괴가 거의 함께 잡히고, 계령괴가 없어도 柴胡劑에는 桂枝茯苓丸을 겸해 쓰는 원장님 임상 규칙을 점수 가중으로 넣음
- 순위가 높은 주증상과 복진 소견이 처방 점수·요약·인쇄에 반영됩니다.
- 판독·처방을 대신하지 않습니다. 변증과 처방의 최종 결정은 복진을 포함한 대면 진찰로 원장님이 내립니다.
- 입력값은 브라우저 안에서만 계산되며 서버로 보내지 않습니다.
