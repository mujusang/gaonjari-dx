# 가온자리 진단툴 · 1차 시안

가온자리한의원 진료 보조 화면의 1차 시안입니다. 단일 HTML 파일(`index.html`)로 되어 있고, GitHub Pages로 배포됩니다.

- 주소: https://mujusang.github.io/gaonjari-dx/
- 구성: 원장님 진료(클릭형) · 환자 문진표(체크형) · 문진표 사진(준비 중)
- 판독·처방을 대신하지 않습니다. 변증과 처방의 최종 결정은 복진을 포함한 대면 진찰로 원장님이 내립니다.
- 문진표 사진 판독·외부 연동은 2차 범위입니다. 입력값은 브라우저 안에서만 계산되며 서버로 보내지 않습니다.

원본 파일: `downloads/가온자리_진단툴_1차시안.html`
